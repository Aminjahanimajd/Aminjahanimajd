## Selected public projects

- **[Two-UAV industrial fire-detection thesis](https://github.com/Aminjahanimajd/Tiered-Edge-AI-Architecture-for-Cooperative-UAV-Based-Industrial-Fire-Detection)** — Completed University of Messina bachelor thesis. Built and measured a Sentinel-Scout prototype with Jetson Nano, VOXL 2, ROS 2, TensorRT FP16, and TensorFlow Lite. The repository documents stationary physical tests and separate flight simulation.
- **[OmniTrade AI](https://github.com/Aminjahanimajd/OmniTradeAI)** — Team-built event-driven analysis platform using Python, FastAPI, React, TypeScript, PostgreSQL, Redis Streams, and Docker.
- **[Raspberry Pi Captive Portal](https://github.com/Aminjahanimajd/RPi_Captive_Portal)** — Flask and SQLite web portal with Pi hotspot setup scripts and a two-node Docker demo of federated key-shard exchange. The Docker encrypted-storage component is simulated.
- **[Battle Arena](https://github.com/Aminjahanimajd/battle-arena)** — Java 17/JavaFX strategy game using Maven and separate domain, engine, infrastructure, and UI controller packages to practice object-oriented design.
- **[CUDA p-Bit Route Planner](https://github.com/Aminjahanimajd/cuda-digital-twin)** — Educational CuPy/CUDA route-selection demonstration connected to a humanoid simulator. The routes and costs are predefined; this is not a perception or physical-robot deployment.
- **[Telecom Customer Churn Prediction](https://github.com/Aminjahanimajd/Tele_Customer_Churn)** — Data cleaning and classification comparison using scikit-learn on a disclosed train/test split.
